# disk-wrapping-witness

A certified lower bound for the maximum volume wrappable by a disk, together with a sharp separation from the rotational-radial class.

This repository accompanies the preprint **“On the Maximum Volume Wrappable by a Disk: A Certified Symmetry-Breaking Lower Bound.”**

## Extremal problem

For the closed disk \(D_R\), define

\[
W(R)=\sup\{\operatorname{Vol}(B): B \text{ is wrappable by } D_R\}
\]

in the 1-Lipschitz wrapping formalization used by Nandakumar. Scaling gives \(W(R)=R^3W(1)\), so the problem is to determine the single dimensionless constant \(W(1)\).

The current paper proves the bracket

\[
0.17984349416291615\ldots
\le W(1)
\le \frac{\pi}{6}
=0.523598775598\ldots .
\]

The upper bound is the immediate consequence of two facts: a 1-Lipschitz image of the unit disk has area at most \(\pi\), and the Euclidean isoperimetric inequality bounds enclosed volume in terms of boundary area.

## Sharp rotational-radial barrier

Let \(W_{\mathrm{rev}}^{\mathrm{rad}}(R)\) be the supremum over solids of revolution generated by a simple north-south meridian of length at most \(R\), wrapped by the direct radial map. The paper shows, without assuming convexity of the meridian, that

\[
W_{\mathrm{rev}}^{\mathrm{rad}}(R)
=\frac{\pi}{12I^2}R^3
=0.152315527\ldots R^3,
\qquad
I=\int_0^1\frac{du}{\sqrt{1-u^4}}.
\]

This is the classical Mylar value. Thus even arbitrary nonconvex rotational profiles cannot improve on Mylar within this class.

## Certified non-axisymmetric construction

The repository contains a 17-vertex, 30-face nonconvex polyhedral wrapping with exact volume

\[
C R^3,
\qquad
C=0.17984349416291615\ldots .
\]

Hence

\[
W_{\mathrm{rev}}^{\mathrm{rad}}(R)
< C R^3
\le W(R),
\]

and the explicit construction crosses the sharp rotational-radial barrier by about **18.07%**. The point of the coefficient \(0.179843\ldots\) is this threshold crossing, not a claim that the coefficient itself is optimal.

At the level of optimal values, this gives a strict symmetry-breaking statement: the unrestricted wrapping problem is strictly better than the rotational-radial subclass.

## Relation to Nandakumar's Question 1

Question 1 asks only whether \(D_\pi\) can wrap some nonconvex solid of volume greater than \(4\pi/3\). Under the stated 1-Lipschitz formalization, the paper gives a short elementary affirmative answer: start with a suitable oblate spheroid whose volume is already larger than the unit ball and whose north-south meridian length is strictly less than \(\pi\), then make a sufficiently small inward rotational notch.

Accordingly, the main contribution of this repository is **quantitative**: a certified lower bound for \(W(1)\) that strictly exceeds a sharp natural symmetry class.

## Exact verification

Two independent exact-arithmetic programs certify the polyhedral witness. They check:

1. the quotient is a connected orientable triangulated 2-sphere with \((V,E,F)=(17,45,30)\);
2. all 30 affine triangle maps are strictly 1-Lipschitz;
3. all 435 unordered target-triangle pairs intersect exactly in their prescribed common simplex;
4. an exact face-plane witness proves nonconvexity; and
5. the enclosed volume equals the exact rational constant used in the paper.

Run:

```bash
# Verifier A: Python 3 + SymPy
python certificate/exact_certificate.py

# Verifier B: Python 3 standard library only
python certificate/independent_verify.py
```

The important checks use explicit `require(...)/raise` logic rather than Python `assert`, so they also remain active under `python -O`.

Both verifiers return

```text
volume decimal = 0.17984349416291615
```

and the exact rational value

```text
359686988325832312742347877865122384142690317017149
/ 2000000000000000000000000000000000000000000000000000
```

## Open problem

The central question is now simply:

\[
\boxed{\text{Determine }W(1).}
\]

Natural intermediate goals are to improve the certified lower bound, lower the universal upper bound \(\pi/6\), decide whether the supremum is attained, and identify other restricted classes with exactly solvable optimal values.

Feedback, independent verification, and pointers to prior equivalent constructions or bounds are very welcome.
